# Computer Science

This section contains solved problems covering areas of computer science such as algorithms, data structures, computational complexity, discrete mathematics, and programming challenges.

## Structure

- `problems/` — Problem statements, named `problem-001.md`, `problem-002.md`, and so on.
- `solutions/` — Step-by-step solutions, named `solution-001.md`, `solution-002.md`, and so on, each matching a problem of the same number.

## Guidelines

- Include time and space complexity analysis for algorithmic solutions.
- Use fenced code blocks with the correct language tag for any code.
- Use LaTeX for mathematical notation where relevant (for example, complexity expressions or discrete math proofs).

See the root `README.md` and `docs/naming-guide.md` for full project conventions.
