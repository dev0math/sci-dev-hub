# Physics

This section contains solved problems covering areas of physics such as mechanics, thermodynamics, electromagnetism, waves, and modern physics.

## Structure

- `problems/` — Problem statements, named `problem-001.md`, `problem-002.md`, and so on.
- `solutions/` — Step-by-step solutions, named `solution-001.md`, `solution-002.md`, and so on, each matching a problem of the same number.

## Guidelines

- State all given quantities, units, and assumptions clearly at the start of a solution.
- Use LaTeX for all equations and include units throughout the derivation.
- Diagrams referenced in a problem should be described or linked clearly if an image cannot be embedded directly.

See the root `README.md` and `docs/naming-guide.md` for full project conventions.
