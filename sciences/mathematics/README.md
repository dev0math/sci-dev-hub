# Mathematics

This section contains solved problems covering areas of mathematics such as algebra, calculus, geometry, number theory, combinatorics, and probability.

## Structure

- `problems/` — Problem statements, named `problem-001.md`, `problem-002.md`, and so on.
- `solutions/` — Step-by-step solutions, named `solution-001.md`, `solution-002.md`, and so on, each matching a problem of the same number.

## Guidelines

- Use LaTeX for all mathematical notation.
- State any theorems or identities used in a solution explicitly, rather than assuming familiarity.
- Where multiple solution methods exist, the primary method should be presented in full; alternative methods may be added under a "Verification" or "Alternative Approach" note.

See the root `README.md` and `docs/naming-guide.md` for full project conventions.
