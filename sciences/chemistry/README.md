# Chemistry

This section contains solved problems covering areas of chemistry such as general chemistry, organic chemistry, physical chemistry, and analytical chemistry.

## Structure

- `problems/` — Problem statements, named `problem-001.md`, `problem-002.md`, and so on.
- `solutions/` — Step-by-step solutions, named `solution-001.md`, `solution-002.md`, and so on, each matching a problem of the same number.

## Guidelines

- Use standard chemical notation and balanced equations where relevant.
- Use LaTeX for chemical formulas and quantitative calculations.
- Clearly state any assumptions about conditions (temperature, pressure, concentration) used in a solution.

See the root `README.md` and `docs/naming-guide.md` for full project conventions.
